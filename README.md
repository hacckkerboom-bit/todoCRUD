# CRUD Todo App

A simple CRUD (Create, Read, Update, Delete) Todo Application built using **HTML**, **CSS**, **JavaScript**, and **MockAPI**.

## Features

* Add new tasks
* View all tasks
* Edit existing tasks
* Delete tasks
* Real-time UI updates after API operations
* Uses Fetch API with Async/Await

## Technologies Used

* HTML
* CSS
* JavaScript (ES6+)
* Fetch API
* Async/Await
* MockAPI

## CRUD Operations

### Create (POST)

Add a new todo task and store it in the API.

### Read (GET)

Fetch and display all todos from the API.

### Update (PUT)

Edit an existing todo and update it in the API.

### Delete (DELETE)

Remove a todo from the API.
